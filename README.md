# Rohit Prem Kumar — Portfolio

Single-page portfolio site for Sport Operations / Event Management job applications.
Plain HTML/CSS/JS, no build step, hosted free on GitHub Pages.

## Local preview

Open `index.html` directly in a browser, or serve it locally:

```
npx serve .
```

## Deploy to GitHub Pages

1. Push this repo to GitHub (e.g. `rohitpkumar.github.io` for a root-domain site, or any repo name for a project site).
2. In the repo, go to **Settings → Pages**, set source to the `main` branch, root folder.
3. Site will be live at `https://<username>.github.io/` or `https://<username>.github.io/<repo-name>/`.
